# Prompt UI - AddCandidatePage

## Objetivo

Rediseñar la página `frontend/src/pages/AddCandidatePage.tsx` para que tenga una apariencia profesional, limpia y responsive, inspirada en una referencia visual adjunta.

## Contexto

- Proyecto React + TypeScript
- La funcionalidad ya funciona end to end
- No cambiar backend ni lógica de negocio
- Mantener validaciones, submit, mensajes de éxito/error y subida de CV
- El diseño debe ser responsive
- Preferencia por Bootstrap 5 para maquetación y estilos base
- Mantener una solución sencilla y fácil de entender para un perfil junior

## Instrucciones

Analiza la imagen de referencia adjunta y propón una adaptación para este caso de uso:

- Lado izquierdo: mensaje de contexto para reclutador
- Lado derecho: formulario de alta de candidato dentro de una card visual
- En desktop: dos columnas
- En móvil: una sola columna apilada
- Mantener jerarquía visual clara
- Botón principal visible
- Alerts de éxito y error bien integradas
- Espaciado limpio y aspecto moderno

## Restricciones

- No generar todavía cambios de código
- Solo proponer estructura visual, secciones, clases Bootstrap sugeridas y archivos a modificar
- No tocar backend
